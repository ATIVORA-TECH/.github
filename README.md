# ATIVORA TECH

### Inteligência que atende. Automação que vende.

---

A **ATIVORA** é uma plataforma SaaS brasileira que une CRM, WhatsApp, IA e
Billing em um só produto. Feita para empresas que querem atender melhor,
vender mais e automatizar o trabalho repetitivo sem perder o toque humano.

## O que fazemos

| Módulo | Descrição |
|--------|-----------|
| **CRM** | Gestão completa de contatos, clientes, oportunidades e pipeline de vendas |
| **WhatsApp** | Atendimento conversacional com IA, atendente automático e fila |
| **IA** | Negociação e suporte automatizados com inteligência |
| **Orçamentos** | Criação, aprovação e conversão de orçamentos em vendas |
| **Billing** | Pagamentos com suporte a PIX, cartão e boleto |
| **Marketing** | Campanhas, pós-venda e automações de comunicação |
| **Calendário** | Agendamento de reuniões e follow-ups com lembretes automáticos |
